# D'Elia Family Adventure: The Shattered Compass

A browser 3D family adventure (three.js r186). Open `index.html` over HTTP (GitHub Pages, or `python3 -m http.server` locally).

- `js/boot.js` loads three.js from jsdelivr, the family models in `models/`, then the game scripts.
- The character build pipeline lives in the project files (`shattered-compass/pipeline/`).
